# W6D5: NL SQL Dashboard on CRM Data

## Objective

Build a Natural Language to SQL workflow for CRM data.

## Database

SQLite database containing:

- Customers
- Orders
- Employees
- Sales

## Vanna / NL to SQL

Created 5 example Natural Language to SQL patterns.

## Query Testing

Tested 10 Natural Language queries and verified the generated SQL.

## SQL Validation

Added validation to allow SELECT queries and block dangerous SQL commands.

## CIA Endpoint

Created:

POST /cia/sql-analyst

The endpoint accepts a Natural Language question and returns SQL.
